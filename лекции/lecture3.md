# Лекция 3. Векторы и строки в C++

Источник: [Яндекс Образование — «Векторы и строки»](https://education.yandex.ru/handbook/cpp/article/vectors-and-strings)

Вектор и строка — два контейнера стандартной библиотеки, которые хранят
элементы **подряд, в одном непрерывном куске памяти**. Именно это свойство
(непрерывность) определяет почти все их особенности: быстрый доступ по
индексу, но дорогую вставку/удаление в середине.

---

## 1. `std::vector` — что это

`std::vector<T>` — динамический массив: при необходимости сам расширяется,
сам освобождает память, когда выходит из области видимости. Тип элементов
задаётся в угловых скобках, потому что `vector` — это не готовый тип, а
**шаблон**: компилятор генерирует конкретный тип (`vector<int>`,
`vector<std::string>` и т. д.) только после подстановки параметра.

Нужен заголовок:

```cpp
#include <vector>
```

Три способа создать вектор:

```cpp
std::vector<int> a = {10, 20, 30};   // список инициализации
std::vector<int> b(5);               // 5 элементов, каждый = 0 (значение по умолчанию)
std::vector<int> c(5, -1);           // 5 элементов, каждый = -1
```

## 2. Доступ к элементам

Индексация с нуля, как в массивах C:

```cpp
std::vector<int> a = {10, 20, 30};
int first = a[0];   // 10
int last  = a[2];   // 30
a[1] = 99;           // {10, 99, 30}
```

**Ключевой момент**: `operator[]` не проверяет границы. Если индекс вышел
за пределы вектора — это неопределённое поведение (программа может
"тихо" прочитать чужую память и не упасть сразу, что хуже, чем явная
ошибка). Это сознательное решение авторов библиотеки: не платить за
проверку, которая нужна не всегда.

Если индекс может быть некорректным и хочется безопасности — есть `.at()`:

```cpp
a.at(0);    // ок, вернёт 10
a.at(100);  // бросит std::out_of_range — можно поймать try/catch
```

Полезные функции:

```cpp
a.size();     // сколько элементов
a.empty();    // true, если элементов 0 (лучше, чем size() == 0)
a.front();    // первый элемент, как a[0]
a.back();     // последний элемент, как a[a.size()-1]
```

`front`/`back` на пустом векторе — тоже неопределённое поведение, поэтому
перед их вызовом стоит проверять `empty()`.

## 3. Итерация и ловушка с `size_t`

`size()` возвращает **беззнаковый** тип `size_t`. Это важно, потому что
арифметика между знаковым и беззнаковым типом в C++ приводит результат
к беззнаковому.

Канонический цикл по индексам:

```cpp
for (size_t i = 0; i != a.size(); ++i) {
    std::cout << a[i] << " ";
}
```

Разбор частой ошибки — поиск подряд идущих одинаковых соседей:

```cpp
// ОШИБКА на пустом векторе
for (size_t i = 0; i < a.size() - 1; ++i) {
    if (a[i] == a[i + 1]) { /* ... */ }
}
```

Если `a.size() == 0`, то `a.size() - 1` не становится "минус единицей" —
беззнаковый тип оборачивается и превращается в огромное положительное
число (например, ≈1.8·10¹⁹ на 64-битной платформе). Цикл начнёт
выполняться и обратится к несуществующему элементу.

Исправление — не вычитать из размера, а прибавлять к индексу:

```cpp
for (size_t i = 0; i + 1 < a.size(); ++i) {
    if (a[i] == a[i + 1]) { /* ... */ }
}
```

Вывод для себя: если в условии цикла встречается `something.size() - N`,
стоит сразу проверить, что будет при пустом контейнере.

## 4. Добавление и удаление элементов

Эффективны только операции **в конце**:

```cpp
std::vector<int> a;
a.push_back(5);   // добавить в конец
a.push_back(7);
a.pop_back();     // удалить последний
a.clear();        // удалить всё
```

Добавление/удаление в середине или начале требует сдвига всех элементов
после точки вставки — поэтому таких отдельных "дешёвых" методов нет,
только через `insert`/`erase` с итераторами (тема отдельного параграфа).

Практический пример: считать числа, пока не кончится ввод, и убрать
хвостовые нули:

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> data;
    int x;
    while (std::cin >> x) {
        data.push_back(x);
    }
    while (!data.empty() && data.back() == 0) {
        data.pop_back();
    }
}
```

## 5. Резерв памяти: `size` vs `capacity`

Вектор хранит элементы плотно, но в конце может быть "запас" под будущие
`push_back`. `size()` — сколько элементов реально есть. `capacity()` —
сколько влезет без реаллокации.

Пока запас не исчерпан, `push_back` — дешёвая операция. Когда он
заканчивается, происходит **реаллокация**: выделяется новый блок памяти
(обычно вдвое больше), старые элементы туда копируются, старый блок
освобождается. Удвоение — не случайность: доказано, что при таком росте
средняя (амортизированная) стоимость одного `push_back` остаётся
константой, хотя отдельные вызовы иногда "дорогие".

![Реаллокация вектора](vector-realloc.svg)

Если заранее известно, сколько элементов понадобится, реаллокаций можно
избежать вызовом `reserve`:

```cpp
std::vector<std::string> words;
size_t n;
std::cin >> n;
words.reserve(n);          // сразу выделили память, size остался 0
for (size_t i = 0; i != n; ++i) {
    std::string w;
    std::cin >> w;
    words.push_back(w);    // теперь без единой реаллокации
}
```

Не путать `reserve` (меняет только запас, `size` не меняется) и `resize`
(меняет реальное количество элементов — лишние в конце удаляются, новые
добавляются с значением по умолчанию):

```cpp
std::vector<int> a = {1, 2, 3, 4, 5};
a.resize(3);   // {1, 2, 3}
a.resize(5);   // {1, 2, 3, 0, 0}
```

## 6. Векторы векторов (матрицы)

Матрица `m × n` — это вектор из `m` векторов длиной `n`:

```cpp
#include <iostream>
#include <vector>

int main() {
    size_t m, n;
    std::cin >> m >> n;

    std::vector<std::vector<int>> grid(m, std::vector<int>(n));

    for (size_t i = 0; i != m; ++i)
        for (size_t j = 0; j != n; ++j)
            std::cin >> grid[i][j];

    for (size_t i = 0; i != m; ++i) {
        for (size_t j = 0; j != n; ++j)
            std::cout << grid[i][j] << "\t";
        std::cout << "\n";
    }
}
```

Идея та же, что с обычным вектором: сначала создаём заготовку из нулей
нужного размера, потом заполняем значениями по индексам `[i][j]`.

## 7. Сортировка

Нужен заголовок `<algorithm>` и функция `sort`, принимающая пару
итераторов — начало и конец диапазона:

```cpp
#include <algorithm>
#include <vector>

std::vector<int> v = {4, 2, 5, 1, 3};
std::sort(v.begin(), v.end());        // 1 2 3 4 5
std::sort(v.rbegin(), v.rend());      // 5 4 3 2 1 (обратные итераторы)
```

По умолчанию сравнение идёт через `<`. Это же позволяет сортировать
векторы векторов — они сравниваются лексикографически, как строки в
словаре: сначала сравнивается первый элемент, при равенстве — второй,
и так далее.

В C++20 то же самое короче: `std::ranges::sort(v);` — без вызова
`begin()/end()` вручную.

## 8. Строки

`std::string` можно представлять как `vector<char>` с дополнительным
набором функций под текстовые задачи. Общие с вектором методы
(`push_back`, `pop_back`, `size`, `resize`, `empty`...) работают
так же.

Специфичные операции:

```cpp
std::string s = "Special string functions";

s.substr(8, 6);        // подстрока длиной 6 начиная с индекса 8 → "string"
s.substr(15);          // от индекса 15 до конца → "functions"

s.find(' ');            // индекс первого пробела
s.find("str");          // индекс первого вхождения подстроки
s.find("xyz");          // если не найдено — std::string::npos

s.insert(8, "new ");    // вставить подстроку по индексу
s.replace(0, 7, "Cool");// заменить диапазон [0;7) на новую строку
s.erase(0, 5);          // удалить 5 символов начиная с индекса 0
```

![Операции со строкой](string-ops.svg)

C++20 добавил проверку префикса/суффикса без ручного `substr`:

```cpp
std::string phrase;
std::getline(std::cin, phrase);

if (phrase.starts_with("hello")) { /* ... */ }
if (phrase.ends_with("bye"))     { /* ... */ }
```

## Итог: на что обратить внимание в первую очередь

1. `operator[]` не проверяет границы — `at()` проверяет и кидает
   исключение. В боевом коде для чужого/непроверенного индекса лучше
   `at()`, в горячем цикле, где индекс точно корректен — `[]` быстрее.
2. `size()` беззнаковый — не вычитать из него напрямую в условии
   сравнения `<`, если контейнер может быть пустым; лучше прибавлять
   к индексу (`i + 1 < size()`), а не вычитать из размера.
3. `push_back` в конец — быстро (амортизированно O(1)), вставка/удаление
   в середину или начало — медленно (O(n) на сдвиг).
4. `reserve` заранее известного количества элементов убирает лишние
   реаллокации — заметная оптимизация при загрузке больших объёмов
   данных.
5. `std::string` — это вектор символов с текстовым API поверх: методы
   вектора работают, плюс `substr/find/insert/replace/erase` для
   текстовых задач.
